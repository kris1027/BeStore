# Landscape check: stack & architecture (2026-09-24)

A haiku researcher ran this check. Anything it marked unverified is not confirmed.

- Framework: Next.js (App Router, current major is 16.x) https://nextjs.org/docs · TanStack Start 1.x https://tanstack.com/start/latest/docs/framework/react/comparison · React Router framework mode (Remix merged; found in search only)
- ORM: Drizzle (1.0 beta available) https://orm.drizzle.team · Prisma (7 and later) https://www.prisma.io
- Auth: Better Auth 1.x, production ready https://better-auth.com · Auth.js is now maintained by the Better Auth team · Clerk is hosted (found in search only)
- Postgres: Neon (serverless, scale to zero, free tier) https://neon.com · Supabase (found in search only) · Vercel Postgres no longer exists (its databases moved to Neon)
- Hosting: Vercel (native Next.js) · Railway / Render / Fly.io (unverified)
- Payments: Stripe Checkout and Payment Element https://docs.stripe.com/payments
- Email: Resend https://resend.com · Postmark (unverified)
- Storage: Vercel Blob, Cloudflare R2, UploadThing (unverified)
- Jobs: Inngest https://inngest.com · Trigger.dev (unverified)
